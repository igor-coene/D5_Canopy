# D5_Coene_Canopy

**Name:** Igor Coene
**Festival:** Canopy, 16–26 June 2027 · “Get lost on purpose”
**Deliverables:** `D5_Canopy.pdf` and the videos are uploaded on Canvas. This repository holds all other files.

## 1_Touchpoint

The core touchpoint: a drone show that spells CANOPY above the city at night, seen by Mark from his window.

| File | What it is | Channel | Spec |
|---|---|---|---|
| `1_Touchpoint/index.html` | Working prototype of the drone show (night window view, drones fly into the word CANOPY, subtitles) | Core touchpoint, non-conventional | HTML + JavaScript, 1 file, runs in any browser |

**How to run it:** download the repository, open `1_Touchpoint/index.html` in a browser (Chrome or Firefox). No installation or internet connection is needed. Use **Replay** to restart the show and **Subtitles** to switch the subtitles on or off. The full loop takes about 34 seconds.
